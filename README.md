# Voda Teleport (Fabric, educational)

Клиентский мод для **Minecraft Java Edition 1.21.11** на **Fabric**.

## Назначение

Мод создан **только для учебных целей**:
- тестирование в одиночной игре;
- локальный тестовый сервер;
- серверы с отключённой проверкой перемещений / античитом.

Мод отправляет на сервер `PlayerMoveC2SPacket` с изменёнными координатами, чтобы показать, как клиент может симулировать быстрый телепорт через сетевой пакет.

## Функции

- Клавиша открытия GUI: `P` (настраивается в `config/vodateleport.json`, поле `openGuiKey`).
- Ввод координат `X/Y/Z` + кнопка **"Телепорт по координатам"**.
- Кнопка **"Сохранить текущую позицию"** и список сохранённых точек (простой аналог `/home`).

## Сборка

```bash
./gradlew build
```

Требуется Java 21.
